# OrbitGuard

OrbitGuard is a Satellite Conjunction & Collision-Risk Alert Platform built for visualizing and analyzing near-Earth orbital traffic. It features a 3D visualization engine for satellite propagation, leveraging real-time SGP4 math to predict potential collision risks.

**Tech Stack**: Next.js 14 (App Router), TypeScript, Tailwind CSS, Three.js (@react-three/fiber), satellite.js, Zustand, and Anthropic Claude for AI-generated risk briefings.

## Getting Started

First, install the dependencies:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
